In this assignment, I learned how to clone a Git repository, create and switch branches, make commits, push changes to a remote repository, and merge branch history back into main.

I also learned how to check out an earlier commit and use the Git reflog to record changes to HEAD. This helped me understand how Git keeps track of repository history even when I move between different commits.

For the programming task, I practiced loading a pretrained ResNet, using the MNIST dataset, resizing images to fit the model input size, running the model, and reporting the test accuracy in a Git commit message.
